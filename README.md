## Ep.6-ตอนจบที่หอมหวาน-บอสตัวร้ายกับนายจิ้งจอกจอมซน
น้องจิ้งจอกยิ้มทั้งน้ำตา “กลับมาแล้วสินะ...”
บอสยื่นกาแฟให้ “แต่โลกนี้บ้าไปแล้วนะ...”
รอบตัวมีโดนัทบิน, ตัวเองจากอีกโลกเล่นม้า, แมวพูดได้เดินผ่าน
น้องจิ้งจอกหัวเราะ “ไม่เป็นไร แค่บอสอยู่ด้วย… โลกไหนก็โอเคแล้ว”
ทั้งคู่เดินจากไปกลางซากจักรวาลที่กำลังผลิบานดอกไม้สีรุ้ง
และแต่งงานกันในที่สุด
