## Ep.5-น้องจิ้งจอกปะทะตัวเองจากอีก999โลก

พอได้รับพลัง น้องจิ้งจอกก็โดนดูดเข้า “ตู้กดน้ำข้ามจักรวาล” ที่โผล่มาแบบงงๆ
แต่ละโลกที่เดินผ่านคือความวายป่วง เช่น โลกที่บอสกลายเป็นโดนัท, โลกที่บอสคือแมวอ้วนใส่แว่น, โลกที่น้องจิ้งจอกเป็นไอดอลติ๊กต่อก
น้องจิ้งจอกตะโกน “ฉันจะช่วยบอสให้ได้!” ก่อนจะโดนตัวเองจากโลกที่ 52 (เวอร์ชันสายแบ๊ว) พุ่งเข้ากอด “โอ๊ย คาวาอี้เกิน!”
ตัวเองจากโลกที่ 88 (เวอร์ชันบอดี้บิลเดอร์) โผล่มาพร้อม “โปรตีนกระโดดข้ามเวลา” แล้วบอก “จะกลับบอสต้องกินนี่ก่อน”
โลกที่ 404 เด้ง Error ทั้งจักรวาลดับ แต่บอสเวอร์ชัน AI ปรากฏขึ้น “พอแล้ว พอซะที!”
น้องจิ้งจอกปลุกพลังดวงตาสีเงิน สร้าง “ค้อนยักษ์ทำลายกฎจักรวาล” ฟาดตูมเดียว โลกทั้ง 999 โลกเชื่อมกันเป็น “ทางด่วนความวาย”
ทันใดนั้นบอสโผล่มาพร้อมกาแฟเย็น “จะช่วยก็ช่วย แต่เอากาแฟชั้นคืนมาก่อน”
น้องจิ้งจอกน้ำตาไหล “บอส…!” ก่อนจะกอด แต่บอสกลายเป็นแมวอ้วนอีกแล้ว
เสียงก้องขึ้น “ยินดีต้อนรับสู่สงครามข้ามจักรวาลเวอร์ชันเถื่อน!”
น้องจิ้งจอกยกนิ้วโป้งให้ตัวเองจากอีกโลก “ลุยกันเถอะ!”
